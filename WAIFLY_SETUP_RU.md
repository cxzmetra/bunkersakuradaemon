# БУНКЕР — подключение сервера через Waifly (бесплатный тариф)

Важно: этот архив подготовлен для развёртывания, но сам сервер ещё НЕ опубликован в интернете. Нужен аккаунт Waifly и созданный сервер в панели.

## 1. Запросить бесплатный доступ
1. Открой https://dash.waifly.com/ask_free
2. Заполни форму самостоятельно и честно опиши проект. Waifly просит описание на английском или французском и подтверждение, что текст не сгенерирован ИИ, поэтому текст формы составь своими словами.
3. После одобрения зарегистрируйся/войдите в панель: https://dash.waifly.com/ и открой Pterodactyl Panel.

## 2. Создать Node.js сервер
1. В панели создай один бесплатный сервер с Node.js (если доступен выбор версии — Node.js 20 или новее).
2. Загрузи содержимое папки `multiplayer_server` из этого проекта в корень серверного контейнера. В корне должны лежать `server.js` и `package.json`.
3. В Startup / запуске укажи `npm start`, если панель позволяет менять команду. Если она выдаёт отдельную команду запуска, используй её.
4. Установи зависимости командой `npm install --omit=dev` через консоль, если панель не устанавливает их автоматически.
5. Запусти сервер и посмотри консоль. Ожидается, что Node.js запустится без ошибки `Cannot find module 'ws'`.

## 3. Сеть и порт — обязательная проверка
Сервер слушает порт из переменных окружения `PORT` или `SERVER_PORT`, а если они отсутствуют — 9080. Используй порт, назначенный панели Waifly; не пытайся открывать произвольный порт.

Найди в панели выделенный адрес/порт (Allocation). Для Godot нужен WebSocket URL, например `ws://HOST:PORT` либо `wss://HOST:PORT`, только если хостинг действительно предоставляет TLS/WSS на этом адресе. Не угадывай схему: сначала проверь документацию/поддержку Waifly или спроси поддержку, как подключаться к WebSocket снаружи. Если панель не даёт публичный TCP-порт для WebSocket или TLS/WSS, этот вариант не заработает без дополнительной сетевой настройки.

## 4. Подключить игру
В Godot открой проект и найди в `scripts/main.gd` строку:

`var network_server_url := "ws://127.0.0.1:9080"`

Замени адрес на реальный внешний WebSocket URL, полученный от Waifly, например `wss://ТВОЙ_АДРЕС:ПОРТ` — только если Waifly подтвердил такой адрес и TLS. Затем собери/экспортируй игру и проверь подключение с двух разных сетей/устройств.

## Ограничения текущей версии
- Список комнат общий только для клиентов, подключённых к одному и тому же запущенному серверу.
- Если бесплатный сервер остановится или перезапустится, лобби в памяти исчезнут.
- Эта версия не является полноценной сервер-авторитетной синхронизацией всей игры; перед публичным релизом нужно отдельно тестировать сетевой игровой процесс, переподключение и безопасность.
- Godot и подключение к Waifly из этой среды не запускались. Не считать это подтверждением работающего онлайна.
