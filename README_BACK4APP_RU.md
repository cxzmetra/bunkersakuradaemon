# BUNKER Beta 27 — вариант публикации на Back4App

1. Прочитайте `BACK4APP_SETUP_RU.md`.
2. В корне проекта есть `Dockerfile`, который собирает WebSocket-сервер из `multiplayer_server`.
3. Сначала загрузите проект в GitHub, затем подключите репозиторий к Back4App Containers.
4. После деплоя проверьте выданный домен и срок его действия. Не считайте онлайн готовым, пока два отдельных клиента не подключились к одному серверу.

Внимание: бесплатный URL Back4App может быть временным; проверяйте актуальные условия в панели.
