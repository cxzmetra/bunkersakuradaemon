# Beta 27 — комнаты и автоматический локальный сервер

## Что теперь делает игра

При нажатии **«Создать сетевую комнату»** игра сама пробует запустить локальный сервер. Отдельно открывать терминал и запускать `npm start` не нужно, если на компьютере установлен Node.js LTS и игра может установить npm-зависимость `ws` при первом запуске.

В лобби есть список **«Открытые комнаты на этом сервере»**. Нажми «Обновить», чтобы запросить список, затем «Присоединиться» у нужной комнаты. Комнаты видны только тем клиентам, которые обращаются к одному и тому же серверу.

## LAN

1. Хост создаёт комнату — сервер запускается автоматически на его компьютере.
2. Другому игроку нужно использовать адрес хоста в локальной сети и порт `9080`, например `ws://192.168.1.20:9080`.
3. В брандмауэре хоста может потребоваться разрешить входящие подключения.
4. Оба игрока обновляют список комнат на одном сервере и присоединяются к нужной комнате.

## Интернет — ограничение, которое нельзя обойти только кодом клиента

Чтобы лобби автоматически показывались игрокам по всему миру без ввода IP/порта, нужен постоянно доступный публичный matchmaking/signaling-сервер или P2P-платформа. Если сервер запущен только на компьютере хоста, игра не может сделать его доступным из интернета сама по себе: мешают NAT, роутер и firewall.

В этой версии публичный сервер не развёрнут и адрес платного/внешнего сервиса не зашит. Поэтому:
- локальный сервер запускается автоматически на хосте;
- список комнат работает в пределах одного адреса сервера;
- для LAN потребуется локальный IP;
- для игры через интернет всё ещё нужен публично доступный relay/signaling endpoint. Не публикуй незашифрованный `ws://` сервер в открытый интернет; используй TLS (`wss://`) и ограничения доступа.

## Если автозапуск не сработал

- Установи Node.js LTS.
- Проверь, что команды `node --version` и `npm --version` работают в терминале.
- Разреши приложению доступ к сети и порту `9080`.
- Если порт занят, останови другой процесс на нём.

Сервер: `multiplayer_server/server.js`; зависимости указаны в `multiplayer_server/package.json`.
