# Beta 23 test checklist

1. Start a new game several times and confirm that the catastrophe and bunker are randomly selected.
2. Open the catastrophe archive and bunker archive: there should be descriptions only, with no select buttons.
3. Confirm that different bunkers start with different resources/capacity/room condition.
4. From active gameplay, return to the main menu; verify the timer stops and “Вернуться в текущую игру” appears.
5. Return to the game and confirm the phase resumes instead of restarting.
6. During profession reveal, use “Скрыть анимацию”; the popup should close while the next profession still respects the 10-second cadence.
7. Confirm the old “Состояние систем жизнеобеспечения” panel is replaced by the current bunker description card.

Godot was unavailable during packaging; these are targeted manual checks, not claimed as completed runtime tests.
