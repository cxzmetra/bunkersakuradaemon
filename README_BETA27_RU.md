# БУНКЕР — Beta 27

Эта сборка добавляет автоматический запуск локального WebSocket-сервера и браузер комнат на одном relay. См. `MULTIPLAYER_BETA27_RU.md` и `CHANGELOG_BETA27_RU.md`.

**Честное ограничение:** публичный сервер для глобального списка комнат не развёрнут. Автозапуск локального сервера не может автоматически открыть его в интернет без публичного relay или настройки сети. Godot не был доступен для запуска в среде подготовки архива, поэтому GDScript следует проверить в самом движке.
