# Beta 19 — последовательное раскрытие и голосование

- Профессии участников раскрываются по одному через очередь полноэкранных уведомлений.
- Профессия игрока синхронизируется с таблицей, поэтому не должна повторно раскрываться в обсуждении.
- Обсуждение начинается только после закрытия последнего уведомления о профессии.
- В карточках голосования показываются все уже раскрытые характеристики каждого доступного кандидата.
- Таймер голосования по умолчанию увеличен до 60 секунд; настройки по-прежнему позволяют выбрать другую длительность.
- Дополнительная характеристика по-прежнему автоматически выбирается случайно по истечении таймера, если игрок не совершил действие вовремя.
- Добавлена очередь полноэкранных уведомлений, чтобы события не накладывались.

Проверки: ZIP проверен на целостность. Запуск в Godot в этой среде недоступен, поэтому игровой запуск и компиляция скрипта не подтверждены.
