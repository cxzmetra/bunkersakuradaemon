# Beta 27 — Auto Lobby & Room Browser

## Что изменено

- При нажатии «Создать сетевую комнату» игра автоматически пытается запустить встроенный WebSocket relay на этом компьютере, если выбран локальный адрес `127.0.0.1`/`localhost`.
- При первом запуске автоматически устанавливается зависимость `ws` через npm. Для этого нужен установленный Node.js LTS и доступ к npm.
- Добавлен запрос списка открытых комнат и отображение комнат, доступных на том же сервере, с кнопкой присоединения.
- Сервер возвращает только незапущенные и незаполненные комнаты; закрытые/устаревшие комнаты очищаются из списка.
- Серверная логика списка комнат не требует вступать в комнату.

## Важно про интернет

Автозапуск устраняет ручной запуск Node-сервера на компьютере хоста, но не создаёт публичную инфраструктуру автоматически. Чтобы друзья из любой сети видели одну и ту же комнату, сервер-ретранслятор должен быть доступен в интернете и у всех клиентов должен быть один и тот же адрес. Для этого нужна развёрнутая публичная служба/хостинг или P2P/signaling-сервис. В этой сборке публичный relay не развёрнут от имени автора проекта.

## Проверки

- `node --check multiplayer_server/server.js` — синтаксис JavaScript проверен.
- ZIP проверен через `unzip -t`.
- Godot в среде сборки не установлен, поэтому GDScript не запускался в движке; проверь проект на двух экземплярах Godot.
