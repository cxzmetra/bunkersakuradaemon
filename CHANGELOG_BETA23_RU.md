# Beta 23 — Random Bunkers, Archives & Resume

- Added a return-to-current-game action in the main menu. Entering the menu from an active game stops the phase timer; returning resumes the game screen and timer state.
- Catastrophe archive is informational only: no scenario selection buttons. The catastrophe is randomly selected for each new game.
- Map archive renamed to bunker archive and is informational only. Bunkers are randomly selected for each new game.
- Removed manual bunker/catastrophe selection from lobby and bunker settings.
- Replaced the generic life-support meter section in the gameplay overview with a current bunker card: description, capacity, area, strengths and risk.
- Selected bunker now changes initial resource levels, bunker capacity limits, and selected room integrity for several locations.
- Added a “hide animation” control to reveal overlays. Hiding the profession splash does not skip the 10-second profession cadence.
- Kept local/offline play. No relationship mechanic or online multiplayer added.

Validation: ZIP integrity checked. Godot runtime was not available in this environment, so in-engine testing is still required.
