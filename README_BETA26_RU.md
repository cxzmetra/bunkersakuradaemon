# БУНКЕР — Beta 26 Multiplayer

Beta 26 — первый прототип общей сетевой партии поверх бесплатного WebSocket-реле. Хост управляет игровой симуляцией, а подключённые клиенты получают состояние партии и отправляют игровые действия хосту.

## Быстрый старт

1. Установи Node.js LTS.
2. Открой терминал в `multiplayer_server`.
3. Запусти `npm install`, затем `npm start`.
4. В Godot запусти проект и открой лобби.
5. Хост: адрес `ws://127.0.0.1:9080` → «Создать сетевую комнату».
6. Друг: адрес `ws://IP-ХОСТА:9080` → введи код комнаты → «Войти по коду».
7. Хост начинает партию после появления друзей в списке участников.

Подробные инструкции для LAN и интернета: `MULTIPLAYER_BETA26_RU.md`.

## Синхронизируемые действия

Фазы и таймеры, случайный катаклизм и бункер, раскрытие характеристик, голоса, пропуск вступления, пропуск хода, спецвозможности, ресурсы и завершение партии. Клиенты не должны самостоятельно продвигать фазы: авторитетный экземпляр — у хоста.

## Ограничения

Сборка не запускалась в Godot в среде подготовки, поэтому сначала проверь её на двух экземплярах Godot. Серверный JavaScript прошёл `node --check`, но для работы нужно выполнить `npm install`. Подключение через интернет требует доступного сервера; бесплатный софт не означает, что публичный хостинг всегда будет бесплатным.
