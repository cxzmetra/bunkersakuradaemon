# Сетевой режим BUNKER — бесплатный прототип

## Что есть в этой сборке
- В Godot добавлен WebSocket-клиент, поле адреса сервера, создание комнаты и подключение по коду.
- В `multiplayer_server/` находится бесплатный сервер комнат на Node.js + `ws` (MIT).
- Сервер пересылает список участников, сообщения чата и сигнал старта от хоста.
- Для теста в одной сети можно указать `ws://IP_КОМПЬЮТЕРА_С_СЕРВЕРОМ:9080`.

## Запуск сервера
1. Установить Node.js LTS с официального сайта.
2. В терминале открыть папку `multiplayer_server`.
3. Выполнить `npm install`, затем `npm start`.
4. Разрешить входящие соединения на порт 9080 в локальной сети.
5. Все участники вводят один и тот же адрес сервера и код комнаты.

## Важно
Это бесплатная основа сетевых комнат, а не завершённый полноценный онлайн-режим. В текущей сборке ещё не синхронизируются авторитетно все игровые действия, случайные характеристики, таймеры, голосование и ресурсы между клиентами. Для полноценной сетевой партии нужен следующий этап: серверная авторитетная модель состояния игры и проверка каждого действия хостом/сервером. Для публичной игры нужен хостинг; код бесплатный, но доступность бесплатного хостинга и домена не гарантируется.
