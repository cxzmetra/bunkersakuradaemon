# Сетевой статус и следующий этап

Текущая версия — локальная игра против ИИ. Чтобы получить настоящий онлайн, следующим отдельным этапом нужно реализовать:

1. Сервер комнат (например, Godot ENet/WebSocket или отдельный backend).
2. Авторитетное состояние партии на сервере: фазы, карты, таймеры, голосование и результаты.
3. Отдельное приватное состояние карт для каждого клиента, чтобы скрытые характеристики не утекали другим игрокам.
4. Вход по коду комнаты, переподключение и обработку выхода хоста.
5. Настоящие команды хоста: kick, ban, mute, смена хоста, ограничение чата, журнал действий и сохранение бан-листа.
6. Проверку безопасности: клиент не должен самостоятельно назначать результаты голосования или читать чужие скрытые карты.

Нельзя считать игру сетевой только потому, что в интерфейсе отображается код комнаты. В этой сборке сетевой сервер не реализован.
