# БУНКЕР — Beta 25

Офлайн-игра с режимами характеристик, большим набором катаклизмов, профилем уровней и двумя спецвозможностями на участника.

## Запуск
Откройте `project.godot` в Godot 4.x.

## Сетевые комнаты (экспериментально, бесплатно)
Инструкции и ограничения: `MULTIPLAYER_BETA_RU.md`. Сервер находится в `multiplayer_server/`.

Для локальной игры сервер запускать не нужно. Никаких платных плагинов или сервисов не используется.
